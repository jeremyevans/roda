module Roda::RodaPlugins::FreezeRequestResponse

  1. lib/roda/plugins/freeze_request_response.rb

The freeze_request_response plugin freezes the RodaRequest and RodaResponse classes when freezing the Roda class. This will become the default behavior in Roda 4.
